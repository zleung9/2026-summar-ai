# Section 1: AI-Native Development & Environment Setup

> Dates: July 29 — July 31

## What This Section Is About

Before you can build anything, you need a working environment and a basic understanding of how to collaborate with AI tools. This section is entirely about getting set up and learning the "AI-native" workflow — where you describe what you want, the AI generates code, and you review, test, and iterate.

By the end of these three days, you should have Python, Git, and Claude Code installed; a GitHub repository for your course project; a personal learning plan; and a rough task list for the polymer materials project you'll build throughout this course.

## Topics

- Install and configure Python, Git, GitHub, Claude Code
- Learn how to describe tasks, provide context, and review code with AI
- Use AI tools to create a personal learning plan
- Learn basic Python project structure

## Three-Day Map

| Day | Focus | Output |
|-----|-------|--------|
| 1 | Set up development environment and GitHub repository | Working tools + a repo on GitHub |
| 2 | Use Claude Code to complete several simple Python programs | Experience writing prompts and reviewing AI-generated code |
| 3 | Build the initial code framework for the polymer materials project | A project scaffold and a task list |

## Recommended Resources

### Python

- **[Python.org Official Tutorial](https://docs.python.org/3/tutorial/index.html)** — Sections 1–5 (Whetting Your Appetite through Data Structures). This is the best place to start. Don't try to read it all at once; use it as a reference while you work.
- **[Real Python: Python Virtual Environments](https://realpython.com/python-virtual-environments-a-primer/)** — Understand why and how to isolate project dependencies. Read the first half (through "Using virtualenv").

### Git & GitHub

- **[GitHub Skills: Introduction to GitHub](https://github.com/skills/introduction-to-github)** — Interactive, ~30 minutes. Do this on Day 1.
- **[Git - The Simple Guide](https://rogerdudler.github.io/git-guide/)** — A one-page overview of the Git commands you'll use daily. Bookmark this.
- **[Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)** — A convention for writing commit messages. Skim the summary; you'll pick up the habit as you go.

### Claude Code & AI-Native Workflow

- **[Claude Code Documentation](https://docs.claude.codes/)** — Start with "Getting Started" and "Core Workflow." You'll learn the rest by doing.
- **[Anthropic Prompt Engineering Guide](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview)** — Read the overview and the section on "Be Clear and Direct." Good prompting is the single most valuable skill in this course.
- **[Claude Code: How to Think About AI-Assisted Development](https://docs.claude.codes/thinking/)** — A 10-minute read on the mental model behind AI-native development.

### Python Project Structure

- **[The Good Research Code Handbook](https://goodresearch.dev/)** — Read the intro and the section on project structure. This is forward-looking; you'll apply these ideas starting in Section 6. For now, just know what good structure looks like.

## Framing Questions

*Don't just read — think. These questions are meant to focus your attention on what matters.*

1. **What makes a good prompt?** After your first few interactions with Claude Code, reflect: which prompts produced exactly what you wanted, and which didn't? What was different about them? Write down 2–3 rules you'd give to a friend who's never used an AI coding tool.

2. **What does Git actually do for you?** After you've initialized a repo and made a few commits, answer this concretely: if your laptop died right now, what would you lose, and what would Git have saved? If you accidentally broke your code, how would Git help you get back to a working version?

3. **What is the polymer materials project, really?** By Day 3, you should be able to describe — in one paragraph, to someone who knows nothing about ML — what you're going to build, what data you'll need, and what "success" looks like. If you can't do that yet, you have more thinking to do.

## Self-Check

After completing this section, you should be able to:

- [ ] Create and activate a Python virtual environment, and install packages into it
- [ ] Initialize a Git repository, stage changes, commit with a meaningful message, and push to GitHub
- [ ] Write a prompt to Claude Code that produces working Python code, then read and explain what the code does
- [ ] Identify at least one problem with AI-generated code and ask Claude Code to fix it
- [ ] Describe the standard directory layout of a Python project (where code, data, tests, and docs go)
- [ ] List the major steps needed to take the polymer materials project from raw data to a trained model
- [ ] Explain — to a non-technical person — what version control is and why it matters

**You know enough when you can answer:** "I have an idea for a Python program. Walk me through exactly what you'd do — from opening your terminal to pushing working code — to build it with Claude Code."
